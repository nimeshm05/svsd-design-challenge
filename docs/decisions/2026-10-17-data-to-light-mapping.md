# What each part of a star means

**Question:** Which data should drive which visual property, so a parent can read the galaxy without a legend after a few days?

**What we chose**

| Data | Visual | Why |
| --- | --- | --- |
| Weight | Core size | Growth is the parents' first question; the galaxy visibly gets bigger. |
| How the day went | Brightness and a cooler tint | Honest without alarm. Hard days are never missing or dark. |
| Parent present | Copper halo, intensity = minutes | Answers the second big stressor (losing the parent role): you can *see* yourself in the sky. |
| Breathing support | Diffraction spikes: more help, more and thinner spikes | Spikes read as "apparatus". As help drops, the star literally simplifies and softens. Room air is a short, soft four-point star. |
| Voice notes | Orbiting motes | Family who can't visit still circle the baby. |
| Firsts | Named in Instrument Serif italic | Milestones deserve names, not icons. |

**Rejected:** colour-coding mood (red/green). It would turn days into grades, and red is banned in this space. Also rejected: hiding hard days or making them dark, which would read as loss.

**Moment types** differ in *shape and motion*, not only colour (feeds flow inward, diapers are diamonds, cares are four-point sparks, voice notes are rings with an orbiting mote, procedures are a calm violet triangle), so colour isn't carrying meaning alone.
